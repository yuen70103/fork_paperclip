## 什麼是回形針？

# 零人公司的開源編排

**如果 OpenClaw 是_僱員_，Paperclip 就是_公司_**

Paperclip 是一個 Node.js 伺服器和 React UI，可協調一組 AI 代理來運作業務。攜帶您自己的代理商、分配目標並透過一個儀表板追蹤代理商的工作和成本。

它看起來像一個任務管理器，但在幕後它有組織結構圖、預算、治理、目標調整和代理協調。

**管理業務目標，而不是拉取請求。 **

| |步驟|範例|
| ------ | ---------------- | ------------------------------------------------------------------ |
| **01** |定義目標 | _“以 100 萬美元的 MRR 打造排名第一的人工智慧筆記應用程式。”_ |
| **02** |聘請團隊|執行長、技術長、工程師、設計師、行銷人員－任何機器人、任何提供者。 |
| **03** |批准並運行 |審查策略。設定預算。打吧。從儀表板進行監控。  |

<br/>

> **即將推出：Clipmart** — 一鍵下載並運行整個公司。瀏覽預先建置的公司範本 - 完整的組織結構、代理配置和技能 - 並在幾秒鐘內將它們匯入到您的 Paperclip 實例中。

## 迴紋針適合您，如果

- ✅ 你想建立**自主人工智慧公司**
- ✅ 你**協調許多不同的代理**（OpenClaw、Codex、Claude、Cursor）以實現共同目標
- ✅ 您有 **20 個同時開啟的 Claude Code 終端機**，卻無法追蹤每個人在做什麼
- ✅ 您希望代理**24/7** 自主運行，但仍希望審核工作並在需要時介入
- ✅ 您想要**監控成本**並執行預算
- ✅ 您想要一個**感覺像是使用任務管理器**的代理管理流程
- ✅ 您想要**透過手機**管理您的自主業務**

|沒有迴紋針 |用迴紋針|

| ❌ 您可以從多個位置手動收集上下文，以提醒您的機器人您實際上在做什麼。                                     | ✅ 上下文從任務一直延伸到專案和公司目標 - 您的代理商始終知道要做什麼以及為什麼要做什麼。                  |
| ❌ 代理程式設定檔夾雜亂無章，您正在重新發明代理程式之間的任務管理、通訊和協調。 | ✅ Paperclip 為您提供開箱即用的組織結構圖、票務、授權和治理 — 這樣您就可以經營一家公司，而不是一堆腳本。 |
| ❌ 失控循環會浪費數百美元的代幣，並在您知道發生了什麼之前就最大化您的配額。                           | ✅ 成本追蹤可顯示代幣預算並在代理商外出時進行限制。管理層優先考慮預算。                    |
| ❌ 您有重複性工作（客戶支援、社交、報告），並且必須記住手動啟動它們。                        | ✅ 心跳依計畫處理常規工作。管理層監督。                                                                |
| ❌ 你有一個想法，你必須找到你的儲存庫，啟動 Claude Code，保持一個選項卡打開，然後照顧它。                                | ✅ 在回形針中新增任務。您的編碼代理會對其進行處理，直至完成。管理階層審查他們的工作。                              |

## 為什麼迴紋針很特別

Paperclip 正確處理硬編排細節。

| | |
|--------------------------------- |---------------------------------------------------------------------------------------------------------------- |
| **原子執行。 ** |任務結帳和預算執行是原子的，因此不會重複工作，也不會出現失控的支出。                      |
| **持久代理狀態。 ** |代理透過心跳恢復相同的任務上下文，而不是從頭開始。                     |
| **運行時技能注入。 ** |代理可以在運行時學習 Paperclip 工作流程和專案上下文，而無需重新培訓。                      |
| **回滾治理。 ** |強制執行批准門，修改配置更改，並且可以安全地回滾不良更改。        |
| **目標意識執行。 ** |任務具有完整的目標血統，因此代理始終可以看到“原因”，而不僅僅是標題。                        |
| **便攜式公司模板。 ** |具有秘密清理和碰撞處理功能的匯出/匯入組織、代理和技能。                          |
| **真正的多公司隔離。 ** |每個實體都是公司範圍的，因此一次部署可以運行許多具有單獨資料和審計追蹤的公司。 |

## 迴紋針不是什麼

| | |
|---------------------------- |-------------------------------------------------------------------------------------------------------------------------------- |
| **不是聊天機器人。 ** |客服人員有工作，沒有聊天視窗。                                                                                  |
| **不是代理框架。 ** |我們不會告訴您如何建立代理。我們告訴您如何經營一家由他們組成的公司。                                |
| **不是工作流程建構器。 ** |沒有拖放管道。 Paperclip 透過組織結構圖、目標、預算和治理對公司進行建模。            |
| **不是提示管理員。 ** |代理帶來自己的提示、模型和運行時。 Paperclip 管理他們工作的組織。
| **不是單一代理工具。 ** |這是針對團隊的。如果您只有一名代理，您可能不需要回形針。如果你有二十個──你肯定有。 |
| **不是程式碼審查工具。 ** | Paperclip 協調工作，而不是拉取請求。帶來您自己的審核流程。                                       |

## 快速入門

開源。自託管。無需回形針帳戶。

```bash
npx paperclipai onboard --yes
```

此快速啟動路徑現在預設為受信任的本地環回模式，以實現最快的首次運行。若要以身份驗證/私有模式啟動，請明確選擇綁定預設：

```bash
npx paperclipai onboard --yes --bind lan
# or:
npx paperclipai onboard --yes --bind tailnet
```

如果您已經配置了 Paperclip，則重新執行 `onboard` 會保留現有配置。使用`paperclipai configure` 編輯設定。

或手動：

```bash
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev
```

這將在 `http://localhost:3100`. 處啟動 API 伺服器，並自動建立嵌入式 PostgreSQL 資料庫 — 無需設定。

> **需求：** Node.js 20+，pnpm 9.15+

## 常問問題

**典型的設定是什麼樣的？ **
在本地，單一 Node.js 進程管理嵌入式 Postgres 和本機檔案儲存。對於生產環境，將其指向您自己的 Postgres 並根據您的喜好進行部署。配置專案、代理和目標－代理負責剩下的事情。

如果您是獨立創業者，您可以使用 Tailscale 隨時隨地存取 Paperclip。然後您可以部署到例如Vercel 在您需要時提供。

**我可以經營多家公司嗎？ **
是的。一次部署可以运行无限数量的公司，并且数据完全隔离。

**Paperclip 與 OpenClaw 或 Claude Code 等代理商有何不同？ **
回形針_使用_那些代理。它將他們編排成一家公司——有組織結構圖、預算、目標、治理和責任。

**為什麼我應該使用 Paperclip 而不是僅僅將我的 OpenClaw 指向 Asana 或 Trello？ **
代理編排在如何協調誰簽出工作、如何維護會話、監控成本、建立治理方面具有微妙之處 - Paperclip 可以為您做到這一點。

（路線圖上有自備門票系統）

**代理是否持續運作？ **
預設情況下，代理程式根據計劃的偵測訊號和基於事件的觸發器（任務分配、@-提及）運行。您也可以掛接 OpenClaw 等連續代理。你帶上你的特工和迴紋針座標。

## 發展

```bash
pnpm dev              # Full dev (API + UI, watch mode)
pnpm dev:once         # Full dev without file watching
pnpm dev:server       # Server only
pnpm build            # Build all
pnpm typecheck        # Type checking
pnpm test             # Cheap default test run (Vitest only)
pnpm test:watch       # Vitest watch mode
pnpm test:e2e         # Playwright browser suite
pnpm db:generate      # Generate DB migration
pnpm db:migrate       # Apply migrations
```

`pnpm test` 不運行 Playwright。瀏覽器套件保持獨立，通常僅在處理這些流程或在 CI 中運行。

請參閱[doc/DEVELOPING.md](doc/DEVELOPING.md) 以取得完整的開髮指南。

## 遙測

Paperclip 收集匿名使用遙測數據，以幫助我們了解產品的使用情況並進行改進。不會收集任何個人資訊、問題內容、提示、文件路徑或機密。私人儲存庫引用在發送之前會使用每次安裝的鹽進行哈希處理。

遙測功能**預設啟用**，並且可以透過以下任一方式停用：

|方法|如何|
| -------------------- | ------------------------------------------------------- |
|環境變數 | `PAPERCLIP_TELEMETRY_DISABLED=1` |
|標準約定| `DO_NOT_TRACK=1` |
| CI 環境 | `CI=true` | 時自動停用
|設定檔 |在回形針配置中設定 `telemetry.enabled: false` |
